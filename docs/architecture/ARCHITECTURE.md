# Архитектура alyaev.it

## Схема

```
                      Internet
                         │
          ┌──────────────▼───────────────┐
          │  proxy (nginx, 80/443)       │  E:\DockerData\nginx
          │  stands/alyaev.conf          │
          └──────────────┬───────────────┘
                         │ npc-proxy-net
          ┌──────────────▼───────────────┐
          │  alyaev-web  (Next.js :3000) │  публичный фронт, SSR/ISR
          │  /api/* → backend            │
          └──────────────┬───────────────┘
          ┌──────────────▼───────────────┐
          │  alyaev-api  (FastAPI :8000) │  бизнес-логика, права, SEO-данные
          └──────────────┬───────────────┘
          ┌──────────────▼───────────────┐
          │  alyaev-db (Postgres 17)     │  E:\DockerData\alyaev-it\pgdata
          └──────────────────────────────┘
```

## Принципы

1. **Один фронт, один бэкенд, одна БД.** Публичный сайт, будущая админка и кабинет живут в одном Next.js и одном FastAPI, но с разными правами.
2. **Права — только на сервере.** UI прячет элементы для удобства, но не защищает.
3. **Контент — в БД.** Цены, тексты услуг, статьи, SEO-поля правятся без деплоя.
4. **SEO — в архитектуре.** SSR, canonical, sitemap, JSON-LD, noindex для служебных путей.
5. **Без опасного состояния на хосте.** Всё в контейнерах, данные только в `E:\DockerData\alyaev-it`.
6. **Общий nginx не ломаем.** Правка только добавлением нового файла в `stands/`, перед reload — `nginx -t`.

## Границы ответственности

| Слой | Отвечает за | НЕ отвечает за |
|---|---|---|
| Next.js | рендер страниц, SEO-теги, формы (черновой UX) | хранение, права |
| FastAPI | валидация, права, CRUD контента, заявки | HTML-шаблоны |
| Postgres | истина по данным | кэши |
| nginx | TLS, маршрутизация, лимиты, кэш статики | логика приложения |

## Маршрутизация

- `/` и публичные страницы — Next.js.
- `/api/*` — проксируется Next.js в FastAPI (rewrite), nginx тоже может отдавать напрямую, если понадобится.
- Будущие `/admin/*` и `/account/*` — сначала Next.js (SSR), данные — через `/api`.

## Решения (ADR)

- ADR-001: Next.js + FastAPI, а не единый Next.js full-stack — ТЗ требует Python для AI/RAG, парсеров и будущих интеграций. См. kaeru note «Стек сайта alyaev.it».
- ADR-002: слияние фронта и бэка в один контейнер — пока не рассматриваем: мешает независимому деплою.
