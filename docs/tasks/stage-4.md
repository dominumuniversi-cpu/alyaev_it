# Этап 4 — Telegram

## T4-01 Бот уведомлений
Новая заявка → сообщение владельцу. Токен — в `E:\DockerData\alyaev-it\.env`, не в репо. Устойчивость: ретраи, лог ошибок, не блокировать сохранение заявки при недоступности Telegram.

## T4-02 Привязка аккаунта
Одноразовый код из кабинета → `/start <code>` у бота → связь `telegram_accounts`. Telegram-аккаунт совпадает по контакту из заявки.

## T4-03 Закрытый канал
Бесплатный уровень для приглашённых. Проверка членства через `getChatMember` там, где бот имеет права. Работает только если владелец добавит бота админом канала (ограничение Bot API).
