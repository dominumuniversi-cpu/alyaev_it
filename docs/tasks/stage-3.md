# Этап 3 — Личный кабинет

## T3-01 Регистрация и вход
Регистрация закрыта: аккаунт создаёт администратор после заказа. Вход по email+пароль, подтверждение email, восстановление пароля по одноразовой ссылке (24 ч), выход со всех устройств, ограничение попыток, защита от перебора.

## T3-02 Проекты
Список своих проектов, статус, задачи, история статусов. Проверка `client_id` обязательна в каждом запросе.

## T3-03 Документы и переписка
Вложения проекта, переписка с историей. Скачивание — только владельцу, через подписанную ссылку.

## T3-04 Уведомления
Изменение статуса, новое сообщение, новый документ. Позже — дублирование в Telegram.
