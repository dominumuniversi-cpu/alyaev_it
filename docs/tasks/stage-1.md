# Этап 1 — Публичный сайт (MVP)

## Приёмка этапа (критерии ТЗ)

- [ ] Все страницы адаптивны (375 / 768 / 1280).
- [ ] Все кнопки имеют назначение, нет пустых блоков.
- [ ] Форма заявки пишет в БД, отдаёт понятную ошибку, защищена rate-limit и honeypot.
- [ ] Уникальные Title/Description на каждой публичной странице.
- [ ] robots.txt, sitemap.xml, canonical, 404, JSON-LD, OG.
- [ ] Метрика подключена, цели на отправку формы.
- [ ] Политика + согласие с фиксацией версии.

## Задачи

### T1-01 Каркас фронта
Layout, Header (fixed, compact), мобильное меню, Footer, шрифты, токены подключены к Tailwind.

### T1-02 Компоненты дизайн-системы
Button, Section, Card, ServiceCard, Badge, Input, Textarea, Select, Accordion, Breadcrumbs. Каждому — манифест в `docs/manifests/ui/`.

### T1-03 Главная страница
10 блоков из ТЗ. Контент — из БД (`services`, `portfolio`, `site_settings`); статические части — в коде как fallback.

### T1-04 Услуги
`/services/` — каталог категорий; `/services/<slug>/` — 8 посадочных. Цены, сроки, что входит/не входит — из БД.

### T1-05 Обо мне
Текст из ТЗ, блок компетенций, подтверждаемые факты (19 лет в IT с 2007), без выдуманных цифр.

### T1-06 Портфолио
Карточки демо-проектов: проблема, архитектура, технологии, статус (демо/свой/коммерческий).

### T1-07 Контакты + заявка
`POST /api/leads`: валидация, honeypot, rate-limit, `consent_version`, `consent_at`, `ip_hash`. Ответ — JSON, без редиректа.

### T1-08 Блог
`/blog/` (список, пагинация), `/blog/<slug>/` (статья, хлебные крошки, «похожие»).

### T1-09 SEO
`sitemap.ts`, `robots.ts`, `generateMetadata` из `seo_metadata`, JSON-LD, OG-картинки, canинальные.

### T1-10 Политика и согласие
`/privacy/`, компонент согласия с версией документа.

### T1-11 Ошибки
404, 500 (error.tsx), 410-обработка удалённых.

### T1-12 Аналитика
Метрика (id из `site_settings`), события: `lead_submit`, `cta_click`, `service_view`.
