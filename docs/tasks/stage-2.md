# Этап 2 — Административная панель

## Принципы

- Панель — часть того же Next.js по `/admin/`, с серверной авторизацией и `noindex`.
- API админки — в FastAPI с проверкой роли в dependency, не в UI.
- Все изменения контента — через `updated_at`, все действия — в `audit_log`.

## Задачи

| ID | Задача | Ключевые требования |
|---|---|---|
| T2-01 | Аутентификация | argon2id, сессии в БД (`sessions`), HttpOnly+Secure+SameSite=Lax, expiry 30 дней, ограничение попыток (5/15 мин), выход со всех устройств |
| T2-02 | Роли и права | Матрица доступа из `schema.md` §9 как серверные guard'ы |
| T2-03 | Услуги и цены | CRUD, drag-sort, публикация, валидация цены и срока |
| T2-04 | Страницы + SEO | Редактор Markdown, SEO-блок с проверкой длины Title/Description, уникальность Title и пути, предпросмотр сниппета |
| T2-05 | Заявки (CRM) | Список с фильтрами, смена статуса (state machine), комментарии, экспорт CSV |
| T2-06 | Портфолио и статьи | CRUD, обложки, публикация, черновики |
| T2-07 | Файлы | Лимит размера, MIME-whitelist, переименование, хранение вне webroot |
| T2-08 | Audit log | Кто, что, когда; фильтры; нельзя удалять записи |
