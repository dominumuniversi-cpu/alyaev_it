## Позиционирование

«Дмитрий Аляев | AI & Business Automation» — персональная IT-студия: автоматизация бизнеса,
AI-разработка, интеграции. Не «разработчик ботов» — а решатель бизнес-проблем.

Главный оффер: «Создаю цифровые решения, которые сокращают рутинную работу, объединяют сервисы
и помогают бизнесу работать эффективнее».

## Главная — блоки (по ТЗ 4.2)

1. Шапка: имя/логотип, навигация, «Обсудить проект», мобильное меню.
2. Hero: позиционирование, результат для клиента, направления, CTA.
3. Компетенции и подтверждаемый опыт (без выдуманных цифр).
4. Категории услуг со стартовыми ценами из БД.
5. Сценарии автоматизации: заявка → обработка → CRM/1С → уведомление → отчёт.
6. Портфолио и демонстрации с явной маркировкой статуса.
7. Преимущества и подход.
8. Этапы работы.
9. FAQ.
10. Последние материалы блога.
11. Финальная форма заявки и контакты.

## Уточнения, принятые при разработке

| Вопрос | Решение |
|---|---|
| Как хранится бренд | Личный бренд, без юридического лица. Schema.org — `Person` |
| География | Россия и русскоязычная аудитория (ТЗ паспорт) |
| Дизайн | Гибрид UIGrammer + корпоративный IT/SaaS (ТЗ паспорт) |
| Кабинет | Полноценный: проекты, задачи, документы, обращения |
| Telegram | Бесплатное закрытое сообщество |
| Архитектура | Модульный монолит, Docker, единая БД |
| Стек | Next.js + FastAPI + PostgreSQL |
| Регистрация клиента | **Админом или по приглашению**, открытой регистрации на старте нет |
| Отзывы | Раздел скрыт до появления подтверждённых отзывов с согласием |

## Чего НЕ входит в первую версию (ТЗ раздел 2)

Внешняя CRM, бухгалтерия и платёжный контур, мобильные приложения, мультиязычность,
маркетплейс модулей, платная подписка и автосписание.
