# Конвейер шагов (ProcessFlow)

> Файл кода: `frontend/src/components/ui/ProcessFlow.tsx`
> Тип шага: `frontend/src/lib/design/process.ts`
> Где стоит: главная, секция «Как решаются задачи» (`#scenario`).

## Что это

Инфографика процесса: карточки шагов, у каждой — номер в круге, надстроенный над рамкой,
и стрелка к следующей. На десктопе — в одну строку из пяти, на планшете — две колонки,
на мобильном — в столбик без стрелок.

## Правила

- Номер шага вычисляется по порядку (`index + 1`) — в данных его писать не надо.
- Стрелка и номер декоративные: `aria-hidden`, смысл несут заголовок и текст шага.
- Шагов 3–6: больше в одну строку не влезает, меньше — конвейер не читается.
- Тексты шагов — короткие (заголовок до 40 знаков, пояснение до 110) иначе ломается сетка.

## Откуда «инструкция»

Схема взята с исходной доски комплекта (`reference/visual-assets-board.webp`) и из `assets-manifest.json`:
там инфографика процесса — три-пять последовательных шагов с номерами и связками.
Доска разобрана вижном 25.11.2026; полный разбор — в `docs/manifests/ui/images.md`.
