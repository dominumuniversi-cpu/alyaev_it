# Манифест: ServiceCard (карточка услуги)

**Файл:** `frontend/src/components/site/ServiceCard.tsx`

## Содержимое (строго в этом порядке)
1. Метка категории (Badge variant tech).
2. Название услуги — ссылка на посадочную страницу.
3. Краткое описание, максимум 140 символов.
4. 2–3 примера задач — маркированный список.
5. Подвал: цена «от N ₽» (Badge price) и срок (Badge muted).

## Данные
Только из GET /api/services. Никаких цен, зашитых в JSX.

## Оформление
- Фон --c-bg-2, рамка --c-border, радиус 16px, padding 24px.
- Hover: рамка золотая на 40%, сдвиг -2px за 160ms.
- Вся карточка кликабельна через ::after у ссылки заголовка.

## Запрещено
- «Цена по запросу» без пояснения.
- Карточка без ссылки на страницу услуги.
