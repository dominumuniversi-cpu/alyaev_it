# Манифест: ServiceCard (карточка услуги)

**Файл:** `frontend/src/components/site/ServiceCard.tsx`

## Содержимое (строго в этом порядке)
1. Метка категории (Badge variant tech).
2. Название услуги — ссылка на посадочную страницу.
3. Краткое описание, максимум 140 символов.
4. 2–3 примера задач — маркированный список.
5. Подвал: цена «от N ₽» (Badge price) и срок (Badge muted).

## Данные
Только из GET /api/services. Никаких цен, зашитых в JSX.

## Оформление
- Фон --c-bg-2, рамка --c-border, радиус 16px, padding 24px.
- Hover: рамка золотая на 40%, сдвиг -2px за 160ms.
- Вся карточка кликабельна через ::after у ссылки заголовка.

## Запрещено
- «Цена по запросу» без пояснения.
- Карточка без ссылки на страницу услуги.

## Иллюстрация карточки (с 25.11.2026)

- Картинка — первым элементом карточки, над бейджем категории.
- Источник: `imageForService(service.slug, service.category_slug)` из `frontend/src/lib/design/images.ts`.
  Руками путь не пишется: единая точка — реестр.
- Размеры берутся из реестра (у файлов разные пропорции: 276×220, 271×160, 263×160); в разметке
  `h-auto w-full max-w-[276px] object-contain` — картинка не растягивается и не искажается.
- Загрузка ленивая (без `priority`), `sizes="(max-width: 640px) 100vw, (max-width: 1024px) 50vw, 380px"`.
- Нет картинки в реестре — берётся общая (`integrations`); пустой рамки не остаётся.
- Текст, цены и подписи в картинку не запекаются: название, описание, цена — HTML.

Соответствие slug → файл и правила — `images.md`.
