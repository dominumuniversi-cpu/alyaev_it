# Манифест: ServiceCard (карточка услуги)

**Файл:** `frontend/src/components/site/ServiceCard.tsx` · **Дизайн:** PERSONAL v2.0

## Структура
| Зона | Содержимое |
|---|---|
| Шапка карточки | название категории (моно 10px, uppercase) + маркер `--c-terracotta` |
| Визуал | уникальная SVG-сцена `PersonalServiceVisual` (высота 150px), фон `--c-paper` |
| Тело | H3 (uppercase, bold), описание, до трёх примеров |
| Подвал | цена (`Badge variant="price"`) и срок (`muted`) |

## Визуалы услуг

Шесть типов сцен в `frontend/src/components/site/PersonalServiceVisual.tsx`:
`telegram`, `ai`, `knowledge`, `automation`, `parser`, `integration`.
Соответствие slug/category — функция `visualTypeFor(slug, category)` в том же файле.

**Одна услуга — один уникальный визуал.** Растровые иллюстрации из `frontend/public/images/services/*` больше не используются:
раньше `telegram-bot.webp` стоял у нескольких услуг — это устранено.

## Правила
- Карточка прямоугольная: рамка `--c-line`, фон `--c-paper-2`, радиус 0.
- Вся карточка — ссылка (`after:absolute after:inset-0`), но H3 остаётся ссылкой для клавиатуры и скринридеров.
- Hover — рамка становится `--c-ink` (без подъёма и теней).
- Внутри SVG нет текста и цен: смысл несут заголовок и описание карточки.
- На мобильном: одна колонка, визуал не создаёт горизонтальной прокрутки.

## Запрещено
- Повторять один визуал у разных услуг.
- Ставить растровую «3D-иллюстрацию» вместо SVG-сцены.
- Выводить больше трёх примеров работ на карточке.
