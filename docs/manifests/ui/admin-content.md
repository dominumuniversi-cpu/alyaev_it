# Манифест: CMS-редактор контента (портфолио и блог)

> Применять при любой работе с `components/admin/PortfolioEditor.tsx`,
> `components/admin/ArticlesEditor.tsx`, страницами `/admin/portfolio`, `/admin/articles`.
>
> **Общий каркас админки** → `docs/manifests/ui/admin-layout.md`.
> **Схема данных** → `docs/manifests/db/schema.md` (таблицы `portfolio`, `articles`).
> **Права** → `docs/manifests/access-control.md` (только `admin`).

## 1. Зачем это существует

ТЗ §12.3: администратор без разработчика должен уметь создать статью, добавить
кейс, отредактировать текст и опубликовать/скрыть материал. До этого всё это
можно было только через API — то есть фактически через программиста.

## 2. Правила, которые нельзя нарушать

| Правило | Почему |
|---|---|
| Все действия — через `fetch`, без перезагрузки страницы | правило владельца: действия пользователя не перебрасывают страницу |
| Ответ 401/403 → перевод на `/login/` | сессия истекла, дальше работать бессмысленно |
| Оптимистичных обновлений нет: после сохранения — перечитать список | правка цены/текста не должна «врать» в интерфейсе |
| Удаление — сразу, без `confirm()`, с возможностью отменить в тосте | правило владельца по UI |
| Ошибка показывается текстом рядом с действием, не алертом |единообразие внешнего вида интерфейса |
| Публикация отдельным переключателем, а не удалением | «скрыть» ≠ «удалить» |

## 3. Страница `/admin/portfolio`

Список кейсов + форма создания/правки.

Поля (совпадают с `PortfolioPayload` в `admin_content.py`):

| Поле | Тип | Обязательное | Ограничение |
|---|---|---|---|
| `slug` | текст | да | 1–160, латиница/цифры/дефис |
| `title` | текст | да | 1–200 |
| `summary` | текст | да | 1–320, видна в карточке списка |
| `problem_md` | многострочный | нет | до 20000, Markdown |
| `solution_md` | многострочный | нет | до 20000, Markdown |
| `technologies` | текст через запятую | нет | до 30 значений |
| `status` | список | да | `demo`, `own`, `commercial` |
| `published` | переключатель | да | по умолчанию выключен |
| `sort_order` | число | нет | по умолчанию 0 |

Статусы и что они значат для посетителя:

| Значение | Подпись на сайте |
|---|---|
| `demo` | Демонстрационный проект |
| `own` | Собственный проект |
| `commercial` | Коммерческое внедрение |

**Честность статуса** — требование ТЗ §5 блок 6: нельзя выдавать демо за
коммерческий кейс. Поэтому статус выбирается явно, а на публичной странице
показывается подписью.

## 4. Страница `/admin/articles`

Поля (совпадают с `ArticlePayload`):

| Поле | Тип | Обязательное | Ограничение |
|---|---|---|---|
| `slug` | текст | да | 1–160 |
| `title` | текст | да | 1–200 |
| `excerpt` | текст | нет | до 320, анонс для списка и SEO |
| `body_md` | многострочный | нет | до 100000, Markdown |
| `status` | список | да | `draft`, `published` |
| `sort_order` | число | нет | по умолчанию 0 |

## 5. Состояния интерфейса

Каждый экран обязан уметь показать четыре состояния, иначе он недоделан:

1. **Загрузка** — «Загружаю…», не пустой экран.
2. **Пусто** — что это значит и что делать («Материалов пока нет — добавьте первый»).
3. **Готово** — список.
4. **Ошибка** — текст ошибки и кнопка «Повторить».

## 7. Адреса API (важно не перепутать)

Все эндпоинты контента живут под префиксом `/api/v1/admin/content`, а не `/api/v1/admin`.
Проверено на живом стенде:

| Действие | Метод и путь |
|---|---|
| Список статей | `GET /api/v1/admin/content/articles` |
| Создать статью | `POST /api/v1/admin/content/articles` |
| Изменить статью | `PATCH /api/v1/admin/content/articles/{id}` |
| Удалить статью | `DELETE /api/v1/admin/content/articles/{id}` |
| Список кейсов | `GET /api/v1/admin/content/portfolio` |
| Создать кейс | `POST /api/v1/admin/content/portfolio` |
| Изменить кейс | `PATCH /api/v1/admin/content/portfolio/{id}` |
| Удалить кейс | `DELETE /api/v1/admin/content/portfolio/{id}` |

Список отдаётся в обёртке `{"items": [...]}`, а не голым массивом.
Создание материала проверяется только через реальный интерфейс: после сохранения
материал должен появиться в списке, а опубликованный — открываться на сайте
по своему адресу.
