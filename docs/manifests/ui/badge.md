# Манифест: Badge (метка статуса)

**Файл:** `frontend/src/components/ui/Badge.tsx`

## Варианты
| variant | Использование | Оформление |
|---|---|---|
| tech | технологии, AI-тематика | голубой текст, голубая рамка с прозрачностью |
| price | цена «от N ₽» | золотой текст, фон золота 10% |
| status | статусы проектов | нейтральная, оттенок задаётся tone |
| muted | вторичные пометки, сроки | серый текст, рамка |

## Правила
- Текст до 24 символов, без переноса строк.
- Метка не кликабельна.
- Не более 3 меток в одной карточке.
