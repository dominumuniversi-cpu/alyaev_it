# Манифест: Badge (метка)

**Файл:** `frontend/src/components/ui/Badge.tsx` · PERSONAL v2.0

| variant | Вид | Где |
|---|---|---|
| `tech` | лаймовая плашка, текст `--c-ink`, радиус 0 | технология, направление |
| `price` | прозрачный, рамка `--c-terracotta`, текст `--c-ink`, semibold | цена услуги |
| `muted` | прозрачный, рамка `--c-border`, текст `--c-text-muted` | срок, второстепенная метка |
| `status` | фон `--c-paper`, рамка `--c-line-2` | статус, метка категории |

Правила: радиус 0 (не «пилюля»), текст до 24 символов, не кликабельна, цвет — только токены.
Раньше использовались `rgba(34,184,230,…)` и `rgba(227,188,122,…)` — удалены 25.11.2026.
