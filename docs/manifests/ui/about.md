# Манифест: страница «Обо мне» (`/about/`)

**ТЗ 8, 11.3, 11.6.** Личная страница — не резюме и не «я люблю технологии».
Задача — показать сочетание IT-опыта, понимания процессов и разработки.

## Структура (сверено с кодом)

| Блок | Обязателен | Что содержит |
|---|---|---|
| H1-секция `#about` | да | абзац опыта, абзац подхода, «Профессиональный опыт», CTA |
| Боковая панель | да | «Чем занимаюсь» — список направлений |
| `#focus` | да | 4 карточки направлений работы (`FeatureCard`) |
| `#mission` | да | «Мой подход» — один абзац |
| Разметка `Person` | да | JSON-LD с именем, должностью, `knowsAbout` |

## Правила

1. **H1 один** — внутри `Section headingLevel={1}`, заголовок «Обо мне и опыте».
2. **Хлебные крошки** — `Главная` + «Обо мне».
3. **Только проверяемые факты.** «В IT с 2007 года» — факт. Проценты экономии,
   «сотни довольных клиентов», «5 лет опыта в AI» — выдумка. Не публиковать.
4. **AI и RAG — как направление разработки**, а не как подтверждённые внедрения,
   пока их нет. Так требует ТЗ 5, блок 3.
5. CTA ведёт на `/contacts/#lead` — форма заявки, не на почту.
6. Тексты — в `COPYWRITING.md`; страница не дублирует главную дословно.

## SEO

| Поле | Значение |
|---|---|
| Title | по ТЗ 11.3: «Обо мне» + основной запрос |
| Description | 120–160 символов, без перечисления должностей |
| H1 | «Обо мне и опыте» |
| Schema.org | `Person` (ТЗ 11.6) |

## Чего страница НЕ делает

- Не показывает отзывы и рейтинги — их нет, а выдуманные запрещены ТЗ.
- Не перечисляет технологии без связи с задачами.
- Не содержит формы заявки внутри — только кнопку перехода.
