# Манифест: Section (контейнер секции)

**Файл:** `frontend/src/components/ui/Section.tsx` · **Дизайн:** PERSONAL v2.0

## Правила
- Каждая секция — `section` с `aria-labelledby` на свой заголовок.
- Заголовок секции по умолчанию — H2; первая секция страницы передаёт `headingLevel={1}`.
- H1: `clamp(34px,5.5vw,68px)`, H2: `clamp(26px,3.6vw,44px)`; оба — `uppercase`, `leading-[0.95…1]`, `tracking-[-0.02em]`.
- Вертикальные отступы — `--space-section` (**`clamp(40px, 5.2vw, 80px)`**, сверено с `globals.css` 26.11.2026); у первой секции сверху треть этого значения (`flat`). Прежние 64–128px уменьшены по просьбе владельца («пробел между блоками большой»).
- Ширина контента — `--shell-max` (**`1400px`**), боковые отступы `--shell-gutter` (**`clamp(20px, 4vw, 56px)`**). Ширина увеличена, чтобы справа не оставалась пустота. Все страницы (включая кабинет и админку) уже на этой сетке.
- Фон: бумага (`--c-paper`) чередуется с графитом (`surface` → класс `.on-dark`). **Больше двух тёмных секций подряд не ставить.**

## Радиусы

- Карточка и панель — `rounded-[var(--radius-md)]` (18px), крупный блок — `rounded-[var(--radius-lg)]` (28px), мелкий элемент — `rounded-[var(--radius-sm)]` (8px).
- Сырые `rounded-xl` / `rounded-2xl` из разметки выведены (28 файлов, 69 замен 26.11.2026): теперь радиус меняется в одном месте — в `globals.css`.

## Тёмная секция

```tsx
<Section id="lead" surface title="…">
```

Внутри `.on-dark` роли токенов переключаются — компонент на `--c-text`/`--c-border` остаётся читаемым.

## Декоративных растровых фонов нет

До 25.11.2026 `Section` принимал prop `backdrop` (bgCircuitBlue и др.) и подкладывал растровую текстуру под каждую секцию.
В PERSONAL v2.0 это отменено: **фон секции — только цвет из токенов**, никаких случайных AI-картинок и плат-текстур.
Prop `backdrop` удалён из компонента; страницы больше его не передают.

## H1 на странице

У каждой страницы ровно один H1. Проверять не по коду ответа, а по разметке: считать `<h1` в HTML.
На главной H1 даёт `Hero`, поэтому её секции остаются H2.
