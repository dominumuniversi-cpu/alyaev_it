# Манифест: Section (контейнер секции)

**Файл:** `frontend/src/components/ui/Section.tsx`

## Правила
- Каждая секция — section с aria-labelledby на свой заголовок.
- Заголовок секции по умолчанию — H2 + необязательный подзаголовок.
- Вертикальные отступы — --space-section (см. tokens.md).
- Максимальная ширина 1200px; боковые отступы 16/24/32px по брейкпоинтам.
- Фон --c-bg и --c-bg-2 чередуется, не более двух смен подряд.

## H1 на странице (добавлено 24.11.2026)

**У каждой страницы обязан быть ровно один H1** — ТЗ §11.1 и §11.3 (таблица «H1»
для каждой страницы), §11.5 (техническое SEO).

Первая секция страницы передаёт `headingLevel={1}`, все остальные — не передают
ничего (по умолчанию H2).

```tsx
// Правильно: главная секция страницы
<Section headingLevel={1} id="services" title="Услуги и цены">

// Правильно: последующие секции той же страницы
<Section id="faq" title="Частые вопросы">
```

### Чем это было

До 24.11.2026 `Section` рендерил заголовок всегда как H2, а страницы состояли
только из секций. В результате H1 отсутствовал на всех страницах, кроме главной
(там он есть в Hero). Дефект нашёлся не по коду, а по проверке живой разметки:
`curl` отдавал 200, но H1 в HTML не было.

### Как проверять

Не по коду ответа, а по разметке: считать `<h1` в HTML страницы. Должно быть
ровно 1. Два H1 — тоже ошибка (характерно для главной: там Hero и первая секция
могут его продублировать).

### Главная страница

H1 на главной даёт Hero, поэтому её секции остаются H2 — `headingLevel={1}`
там **не** ставится.
