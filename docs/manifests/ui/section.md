# Манифест: Section (контейнер секции)

**Файл:** `frontend/src/components/ui/Section.tsx`

## Правила
- Каждая секция — section с aria-labelledby на свой заголовок.
- Заголовок секции: H2 + необязательный подзаголовок.
- Вертикальные отступы — --space-section (см. tokens.md).
- Максимальная ширина 1200px; боковые отступы 16/24/32px по брейкпоинтам.
- Фон --c-bg и --c-bg-2 чередуется, не более двух смен подряд.
