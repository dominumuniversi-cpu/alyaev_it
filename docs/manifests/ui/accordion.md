# Манифест: Accordion (FAQ)

**Файл:** `frontend/src/components/ui/Accordion.tsx`

## Разметка
details/summary — работает без JS. Анимация раскрытия — через CSS.

## Правила
- Заголовок — точный вопрос клиента.
- Ответ до 600 символов.
- Открыт только первый пункт.
- Схема FAQPage в JSON-LD **обязательна**, если FAQ показан на странице: разметка
  строится из тех же вопросов и ответов, что видит пользователь. Поисковики
  (Google и Яндекс) требуют совпадения разметки с содержимым; расхождение —
  нарушение правил и риск ручных санкций.
- Помощник `faqSchema()` в `components/seo/JsonLd.tsx` отбрасывает пустые вопросы.
  Размечать FAQ, которого нет на странице, запрещено.

## Доступность
summary фокусируется, Enter/Space раскрывает. Роль элемента не переопределять.
