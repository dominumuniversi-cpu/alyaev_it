## Обязательные части
1. label связан с полем (htmlFor = id), видим всегда.
2. Подсказка (необязательно) — под меткой, мелким текстом.
3. Поле ввода: рамка --c-border, фон --c-bg-2, радиус 10px.
4. Текст ошибки — под полем, с aria-describedby.
5. Обязательность — aria-required, а не только звёздочка.

## Состояния
| Состояние | Вид |
|---|---|
| обычное | рамка --c-border |
| фокус | рамка --c-cyan + outline 2px, offset 2px |
| ошибка | рамка #E5534B + текст ошибки |
| disabled | прозрачность 50%, cursor not-allowed |
| отправка | поля readOnly, кнопка в состоянии loading |

## Поля формы заявки
| Поле | Тип | Обязательное | Ограничения |
|---|---|---|---|
| Имя | text | да | 2–100 символов |
| Telegram или телефон | text | да | 3–64 символа |
| Тип задачи | select | нет | категории услуг из БД |
| Описание | textarea | да | 20–5000 символов, счётчик |
| Сайт компании | url | нет | http(s) или пусто |
| Согласие | checkbox | да | ссылка на политику, версия фиксируется |

## Запрещено
- Плейсхолдер вместо метки.
- Ошибка только цветом.
- Очистка формы до ответа сервера.
- Перезагрузка страницы после отправки: только fetch и локальное состояние.

## Предзаполнение из ссылки

Поле может прийти с готовым значением из параметров адреса — например, клиент пришёл
с калькулятора. Правила:

1. Предзаполненное значение **редактируемо** — клиент всегда может исправить или стереть.
2. Подставляется только то, что клиент видел и подтвердил на прошлом шаге (услуга, сумма, опции).
3. Текст-приписка отличается от обычного текста клиента: начинается с явной пометки
   «Расчёт с калькулятора:», чтобы владелец видел, что это не свободный текст.
4. Читать параметры только в браузере (`useEffect`), не при серверном рендере.
