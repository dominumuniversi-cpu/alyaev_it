# Манифест: Поля формы (Field)

**Файл:** `frontend/src/components/ui/Field.tsx` · **Сверено с кодом 26.11.2026**

## Классы поля

Единственный источник вида поля — `BASE_INPUT` в `Field.tsx`. Наружу экспортируется `INPUT_CLASS` —
для самодельных `select` / `textarea` / числовых полей, которые не влезают в компонент. Скопировать строку
классов в страницу нельзя: правка манифеста до них не дойдёт.

| Свойство | Значение |
|---|---|
| Ширина | `w-full` |
| Радиус | `10px` |
| Рамка | `--c-line`, в состоянии ошибки — `--c-danger` |
| Фон | `--c-paper` |
| Текст | `--c-ink`, плейсхолдер — `--c-muted` / 60% |
| Фокус | `ring-2` цветом `--c-terracotta`, `ring-offset-2` цветом `--c-paper` |
| Отступ | `px-3.5 py-2.5`, кегль `text-sm` |

## Правила

1. Состояние `disabled` **не реализовано** — если понадобится, добавляется в `INPUT_CLASS`, а не на странице.
2. Ошибка — свойство компонента, а не отдельный класс на месте.
3. Пять мест, где поля были свёрстаны руками (админка SEO, проекты, семантика, кабинет ×2), переведены на
   `INPUT_CLASS` — правка рамки или радиуса теперь меняет их все.
