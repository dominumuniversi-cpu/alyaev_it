## 1. Железное правило: без согласия — не публикуем

Отзыв попадает на сайт, только если выполнены **оба** условия:

1. `status = 'published'`;
2. `consent_given = true`.

Это проверяет `list_public_reviews` в `app/repo/public_data.py`. Даже если админ
переключит статус на «опубликован», но согласия нет — отзыв не появится.
Требование ТЗ §5 блок 9 и §12.6: публикация данных о человеке только с его согласия.

## 2. Поля

| Поле | Тип | Обязательное | Что значит |
|---|---|---|---|
| `author_name` | текст | да, ≤120 | Имя или название компании |
| `author_position` | текст | нет, ≤120 | Должность |
| `text` | текст | да | Текст отзыва |
| `project_title` | текст | нет, ≤200 | По какому проекту |
| `consent_given` | флаг | да | Согласие автора на публикацию |
| `consent_version` | текст | нет, ≤16 | Версия текста согласия |
| `status` | список | да | `draft`, `published`, `archived` |
| `sort_order` | число | нет | Меньше — выше |

Поля `consent_at` и `published_at` сервер ставит сам: дату согласия — когда флаг
включили, дату публикации — когда статус стал `published`. Вручную не задаются.

## 3. Что происходит при переключении флагов

| Действие | `consent_at` | `published_at` |
|---|---|---|
| Включили `consent_given` | запоминается текущий момент | не меняется |
| Выключили `consent_given` | обнуляется | обнуляется, статус сбрасывается в `draft` |
| Статус стал `published` | не меняется | запоминается текущий момент |
| Статус стал `draft`/`archived` | не меняется | обнуляется |

Сброс статуса при отзыве согласия — намеренное: согласие отозвали, значит и
публикации быть не должно, без ручного вмешательства.

## 4. Адреса API

| Действие | Метод и путь |
|---|---|
| Список отзывов | `GET /api/v1/admin/reviews` |
| Создать | `POST /api/v1/admin/reviews` |
| Изменить | `PATCH /api/v1/admin/reviews/{id}` |
| Удалить | `DELETE /api/v1/admin/reviews/{id}` |
| Публичные отзывы | `GET /api/v1/public/reviews` |

Список отдаётся в обёртке `{"items": [...]}`. Удаление мягкое: проставляется
`deleted_at`, запись остаётся в базе.

## 5. Цвет и смысл на странице

Отзыв без согласия в админке помечается предупреждением — администратор видит,
почему отзыв не на сайте, вместо того чтобы искать причину.

Пустой список отзывов на сайте — норма: блок просто не показывается
(ТЗ §5 блок 9: «пока отзывов нет, блок можно не показывать»).
