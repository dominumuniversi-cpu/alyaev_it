# Манифест: Hero (главный экран)

**Файл:** `frontend/src/components/site/Hero.tsx` · первая секция главной

## Содержимое слева
1. Надзаголовок капсом: «Автоматизация бизнеса и AI-разработка».
2. H1 до двух строк.
3. Лид-абзац о результате для бизнеса, а не о технологиях.
4. Строка направлений: Telegram-боты · AI-ассистенты · CRM · API · Парсеры · Сайты.
5. Кнопки «Обсудить проект» (primary) и «Посмотреть услуги» (secondary).
6. Три тезиса: под ключ, индивидуальная оценка, поддержка и развитие.

## Справа
Композиция из карточек-панелей (заявка → обработка → уведомление). Только SVG и CSS, без тяжёлых изображений.

## Производительность
- H1 рендерится на сервере.
- Никаких анимаций, влияющих на LCP; свечение — CSS-градиент.
- Высота первого экрана не фиксируется жёстко.
