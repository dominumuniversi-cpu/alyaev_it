# Манифест: Hero (главный экран)

**Файл:** `frontend/src/components/site/Hero.tsx` · **Дизайн:** PERSONAL v2.0

## Задача
За один экран объяснить, кто это и чем занимается: цифровая студия одного сильного IT/AI-специалиста.
Заголовок — крупный и почти во всю ширину, справа — техническая схема, а не декоративная картинка.

## Структура
| Элемент | Правило |
|---|---|
| Надзаголовок | моно 11px, `uppercase`, `tracking-[0.22em]`, `--c-terracotta`: «Автоматизация бизнеса / AI-разработка / системная интеграция» |
| H1 | `clamp(38px,7vw,92px)`, uppercase, `leading-[0.92]`, три строки: «Сложные процессы. **Понятные** системы.»; слово «Понятные» — на лаймовой плашке |
| Лид | 18–20px, `--c-ink-2`, одно-два предложения о сути работы |
| Направления | моно 12px, `uppercase`, `CRM · API · 1С · Сайты · Автоматизация` |
| Действия | primary «Обсудить проект ↗» → `/contacts/#lead`, secondary «Смотреть услуги» → `/services/` |
| Маркеры | три пункта списком с тире-маркером цвета `--c-terracotta` |
| Правая колонка | `HeroArt` (сцена пакета `p-hero-art`: сетка модулей, орбита, ядро системы на акценте темы, машинная подпись) + под ней `HeroSchema`: три шага конвейера (Заявка → Обработка → Результат) в рамке на `--c-paper-2` |
| Мобильный | сцена не скрыта: под заголовком и лидом, высота 220–260px, чтобы нижний правый угол не «пустел» и на телефоне |

## Правила
- LCP — текстовый заголовок. Растровой картинки на первом экране нет (прежний `hero-visual.webp` снят с главной).
- Заголовок занимает почти всю ширину: `clamp(40px,6.4vw,104px)`; лид ограничен `42ch`, чтобы не расползался в одну длинную строку.
- Ровно две кнопки, обе видны на мобильном и складываются в столбик.
- Сетка: `lg:grid-cols-[1.15fr_.85fr]`, на мобильном — одна колонка, схема идёт после текста.
- Ни одной анимации на первом экране, кроме обычных hover-переходов.
- Никаких градиентов, glow и «космических» фонов — только `--c-paper` и линии.

## Запрещено
- Заголовок в две строки мелким кеглем (сужает первый экран).
- Декоративный скриншот-«мокап» ноутбука или телефона.
- Более одной primary-кнопки.
