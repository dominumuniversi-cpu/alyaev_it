# Манифест: Hero (главный экран)

**Файл:** `frontend/src/components/site/Hero.tsx` · первая секция главной

## Содержимое слева
1. Надзаголовок капсом: «Автоматизация бизнеса и AI-разработка».
2. H1 до двух строк.
3. Лид-абзац о результате для бизнеса, а не о технологиях.
4. Строка направлений: Telegram-боты · AI-ассистенты · CRM · API · Парсеры · Сайты.
5. Кнопки «Обсудить проект» (primary) и «Посмотреть услуги» (secondary).
6. Три тезиса: под ключ, индивидуальная оценка, поддержка и развитие.

## Справа
Правая колонка — иллюстрация из реестра (`heroVisual` из `frontend/src/lib/design/images.ts`)
и под ней композиция из карточек-панелей (заявка → обработка → уведомление).

**Про изображение:** с 25.11.2026 здесь стоит `hero/hero-visual.webp` (340×300) через `next/image`.
Раньше в этом манифесте было «только SVG и CSS, без тяжёлых изображений» — правило устарело:
картинка маленькая, показывается скромно (`max-w-[340px]`, `h-auto`, не растягивается) и не сдвигает
текст: у неё явные `width`/`height`. Полные правила по картинкам — `images.md`.

## Производительность
- H1 рендерится на сервере.
- Никаких анимаций, влияющих на LCP; свечение — CSS-градиент.
- LCP — заголовок H1 (текст), а не картинка. Иллюстрация грузится с `priority` и `sizes="(max-width: 768px) 100vw, 540px"`.
- На узких экранах иллюстрация стоит над панелями и не выталкивает первый экран: ширина ограничена 340 px.
- Высота первого экрана не фиксируется жёстко.
