# Манифест: SEO-панель страницы

**ТЗ 11.1:** у каждой страницы свой блок SEO в админке, редактируется без программиста.
**ТЗ 11.5:** уникальные Title/Description, canonical, robots, noindex для закрытых разделов.

## Источник истины

SEO хранится в таблице `seo_metadata` (`docs/manifests/db/schema.md` §4) и **перекрывает**
автоматические значения из услуги/статьи. Порядок разрешения:

1. Запись `seo_metadata` по пути — если есть, используется она.
2. Иначе — значения из сущности (название услуги, краткое описание).
3. Иначе — общие значения сайта.

**Правило:** админка никогда не «придумывает» Title при сохранении — сохраняет то, что ввели.
Пустое поле означает «использовать автоматическое», а не «пустой тег».

## Поля и правила заполнения

| Поле | Обязательное | Пределы | Проверка |
|---|---|---|---|
| SEO Title | да | 30–60 символов | предупреждение вне диапазона, ошибка при > 160 |
| Description | да | 70–160 символов | предупреждение вне диапазона, ошибка при > 320 |
| H1 | нет | ≤ 200 | предупреждение, если пусто |
| Keywords | нет | — | только для внутренней работы, **не** для ранжирования |
| Canonical | нет | ≤ 255 | пусто = текущий путь |
| Robots index / follow | да | — | переключатели |
| OG title / description | нет | как у Title / Description | пусто = взять из Title / Description |
| OG image | нет | ≤ 255 | путь к изображению |
| Schema.org | нет | jsonb | JSON-LD; невалидный JSON не сохраняется |

## Проверки, без которых панель бесполезна

| Проверка | Уровень | Почему |
|---|---|---|
| Title уникален на сайте | **ошибка** | дубли Title — главная причина, по которой страницы не выводятся |
| Description заполнен | предупреждение | пустое описание поисковик заменит своим куском текста |
| Title вне 30–60 | предупреждение | обрежется в выдаче |
| Description вне 70–160 | предупреждение | обрежется или выглядит пустым |
| H1 пусто | предупреждение | без H1 страница теряет структуру |
| Path занят другой страницей | **ошибка** | создаст дубль URL |

**Ошибка** блокирует сохранение. **Предупреждение** — нет: редактор может знать лучше.
Но предупреждение видно на экране, а не в логах.

## Закрытые разделы (не индексируются никогда)

`/account/`, `/login/`, `/register/`, `/admin/`, `/api/` — `noindex, nofollow` принудительно.
Переключатель в панели для них не действует: это не настройка, а правило безопасности ТЗ 11.5.

## Запрещено

- Задавать Title/Description в коде страницы в обход `seo_metadata`.
- Писать `meta keywords` в расчёте на ранжирование — Google его не использует.
- Хранить в `schema_json` фиктивные рейтинги и отзывы (ТЗ 11.6).
