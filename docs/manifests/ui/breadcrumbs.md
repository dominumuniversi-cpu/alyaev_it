# Манифест: Breadcrumbs (хлебные крошки)

**Файл:** `frontend/src/components/ui/Breadcrumbs.tsx`

## Правила
- Первый элемент — «Главная» → /.
- Последний — текущая страница, не ссылка, aria-current="page".
- Разделитель «/» декоративный (aria-hidden).
- JSON-LD BreadcrumbList строится из того же массива, что и визуальные крошки.

## Где обязательны
Все страницы второго уровня и глубже: услуги, портфолио, блог, документы.
