# UI-манифест: Tokens (дизайн-токены)

**Файлы:** `frontend/src/app/globals.css` (значения), `frontend/tailwind.config.ts` (классы)
**Статус:** действует с 25.11.2026 — дизайн-система **PERSONAL v2.0**. Заменяет тёмную палитру v1 полностью.

## 1. Палитра

Графит и бумажный оттенок — основа. Лайм и терракота — акценты. **Синий основным цветом больше не является.**

| `--c-ink` | `#242522` | Основной текст, тёмные секции (Graphite) |

| `--c-line-2` | `#B9B3A4` | Усиленная граница, рамка панели |

### Совместимость старых имён

Разметка, написанная до редизайна, использует имена `--c-bg`, `--c-gold`, `--c-cyan` и т. п.
Они **не удалены**, а перенаправлены на новую палитру — так редизайн идёт постранично, без «всё сразу».

| Старое имя | Теперь указывает на |
|---|---|
| `--c-bg` | `--c-paper` |
| `--c-surface` | `--c-paper-2` |
| `--c-surface-2` | `#FFFFFF` |
| `--c-border` / `--c-border-strong` | `--c-line` / `--c-line-2` |
| `--c-gold` / `--c-gold-dim` | `--c-lime` / `#A5CE58` |
| `--c-cyan` | `--c-terracotta` |
| `--c-text` / `--c-text-muted` | `--c-ink` / `--c-muted` |

Новые компоненты пишут **только новые имена**. Старые доживают до конца миграции и затем удаляются.


> **26.11.2026, сверка с кодом.** Файл `globals.css` содержит 38 переменных (76 объявлений с учётом `html.dark`).
> Проверено `grep` по `frontend/src`: сырых `rounded-xl` / `rounded-2xl` в разметке больше нет — 28 файлов переведены
> на `--radius-sm/md/lg`, поэтому радиус карточек меняется в одном месте. `--c-muted` = `#6E6F66`, `--c-lime-ink` = `#2F4A12`.

## 2. Служебные токены и алиасы (сверено с `globals.css` 26.11.2026)

Значения проверены построчным сравнением файла и этой таблицы: 38 переменных в CSS — 47 строк здесь.

| Токен | Значение | Роль |
|---|---|---|
| `--c-blue` | `#6E9DA0` | Редкий технический акцент пакета; основным цветом или фоном секции не бывает |
| `--c-grid-line` | `rgba(36,37,34,.055)` | Линия технической сетки фона страницы |
| `--c-veil` | `rgba(234,231,223,.9)` | Мягкое затемнение к краям: сетка не мешает чтению |
| `--c-surface-1` | `var(--c-paper-2)` | Легаси-алиас, используется в админке (иначе плашки прозрачные) |
| `--shell-max` | `1240px` | Ширина контейнера всех страниц |
| `--shell-gutter` | `clamp(20px,5vw,76px)` | Поля контейнера |
| `--space-section` | `clamp(56px,7vw,104px)` | Вертикальный шаг секций |
| `--radius-sm` / `--radius-md` / `--radius-lg` | `8px` / `18px` / `28px` | Радиусы из пакета: мелкие элементы / карточки / крупные панели |
| `--shadow-paper` | `0 24px 80px rgba(20,21,18,.12)` | Единственная тень системы: «поверхность из бумаги», без AI-свечений |

**Правило.** Легаси-алиасы (`--c-bg`, `--c-surface`, `--c-surface-2`, `--c-border`, `--c-border-strong`,
`--c-gold`, `--c-gold-dim`, `--c-cyan`, `--c-text`, `--c-text-muted`) существуют только чтобы кабинет,
админка и формы не потеряли цвет. Новый код обязан брать ролевые имена (`--c-paper`, `--c-ink`, `--c-lime`,
`--c-terracotta`). Удалять алиас можно, когда `grep` по `frontend/src` показывает ноль ссылок.

**Миграция завершена 26.11.2026.** Старые имена больше не используются ни в одном компоненте:
59 файлов / 337 строк переведены на ролевые имена. Проверка — `grep` по `frontend/src`:

| Было | Стало | Почему |
|---|---|---|
| `--c-text` | `--c-ink` | в тёмной теме `--c-text` был светлым, в светлой — графитовым: одно имя, два смысла |
| `--c-text-muted` | `--c-muted` | то же; `--c-muted` переопределяется темой явно |
| `--c-border`, `--c-border-strong` | `--c-line`, `--c-line-2` | «граница» и «линия» смешивались в разметке |
| `--c-surface`, `--c-surface-1`, `--c-surface-2` | `--c-paper-2`, `--c-paper` | три разных «поверхности» в одном компоненте |
| `--c-gold`, `--c-gold-dim` | `--c-lime-ink` (текст), `--c-lime` (плашка) | золото первой темы = акцент сегодня |
| `--c-cyan` | `--c-terra-ink` | синий ушёл из системы |

Алиасы остаются объявленными в `:root` как предохранитель для админки, но **новый код их не берёт**.
**Тёмные секции.** Класс `.on-dark` переопределяет роли на графите: фон `--c-ink`, текст `--c-paper`,
линии — полупрозрачная бумага. Никаких отдельных «тёмных» HEX в разметке.

## 2a. Тёмные секции

Тёмная секция включается классом `.on-dark` (её ставит `Section surface`): внутри роли токенов переключаются,
и компонент, написанный на `--c-text` / `--c-border`, автоматически становится читаемым на графите.

```css
.on-dark { --c-bg: var(--c-ink); --c-text: var(--c-paper); --c-gold: var(--c-lime); ... }
```

Больше двух тёмных секций подряд на странице не ставить.

## 3. Типографика

| Токен | Значение |
|---|---|
| `--font-display` | `Inter, system-ui, …` — заголовки |
| `--font-sans` | `Inter, system-ui, …` — текст |
| `--font-mono` | `JetBrains Mono, ui-monospace, monospace` — номера, служебные подписи, `uppercase tracking-[0.18em]` |

Правила:

- H1 страницы: `clamp(38px, 7vw, 92px)`, `uppercase`, `leading-[0.92]`, `tracking-[-0.03em]`. Заголовок может занимать почти всю ширину.
- H2 секции: `clamp(26px, 3.6vw, 44px)`, `uppercase`.
- Подпись-надзаголовок: моно 11px, `uppercase`, `tracking-[0.22em]`, цвет `--c-terracotta`.
- Абзац-лид: 18–20px, `leading-relaxed`, `--c-ink-2`.
- Не более трёх размеров на экран.

## 4. Сетка и ритм

**Проверено на живом сайте 26.11.2026:** все страницы (главная, услуги, портфолио, обо мне, контакты, блог,
калькулятор, решения, диагностика, вход, кабинет, админка, приватность) используют `--shell-max`
и `--shell-gutter`. Старые значения 1320px и 1200px в разметке отсутствуют — сплошная проверка даёт 0 совпадений.

| Токен | Значение |
|---|---|
| `--space-section` | `clamp(40px, 5.2vw, 80px)` — вертикальный отступ секций |
| `--shell-max` | `1400px` — ширина контента (сменила 1200px) |
| боковые отступы | 16 / 24 / 32px (мобильный / планшет / десктоп) |
| радиусы | `0` для кнопок, карточек и панелей; `999px` только для круглых маркеров; `8px` для полей ввода |

**Асимметрия обязательна:** одинаковые карточки в ряд допустимы только для списков однотипных сущностей (каталог услуг).
Первый экран, «Обо мне», CTA — собираются из неравных колонок и крупной типографики.

## 5. breakpoints

| Точка | Что происходит |
|---|---|
| 375px | базовая колонка, крупный H1 ужимается через `clamp` |
| 640px | карточки в 2 колонки, появляется CTA в шапке |
| 768px | планшетные сетки |
| 1024px | `lg`-сетки, боковые отступы 32px |
| 1280px (`xl`) | полное меню в шапке (до этого — бургер) |

## 6. Состояния

| Состояние | Правило |
|---|---|
| `:focus-visible` | `outline: 2px solid var(--c-terracotta); outline-offset: 2px` |
| hover ссылки | `--c-terracotta` (на светлом), `--c-lime` (на графите) |
| disabled | opacity .45, `cursor: not-allowed` |

## 7. Запрещено

- Новые цвета без согласования: любой HEX в компоненте — дефект, кроме `globals.css`.
- `rgba(...)` со старыми каналами (синий/золотой) — наследие v1.
- Тёмная тема `color-scheme: dark` — отменена, сайт светлый.
- Синий и золотой как акцентные цвета.
