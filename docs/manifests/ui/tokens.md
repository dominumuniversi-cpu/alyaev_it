# Дизайн-токены (единый источник истины)

> Файл кода: `frontend/src/styles/tokens.css` (CSS-переменные) и `frontend/tailwind.config.ts`.
> **Правило:** в манифестах UI и в компонентах нельзя писать сырые HEX — только имена токенов.

## 1. Цвет

| Токен | HEX | Назначение |
|---|---|---|
| `--c-bg` | #05070D | Основной фон страниц |
| `--c-surface` | #0B1220 | Вторичный фон: карточки, панели |
| `--c-surface-2` | #0F1A2B | Вложенные панели, hover-фон |
| `--c-border` | #1D2A3A | Границы, разделители |
| `--c-border-strong` | #2A3B50 | Границы активного/фокус-состояния |
| `--c-gold` | #E3BC7A | Основные действия, важные акценты |
| `--c-gold-dim` | #B8935A | Hover золотой кнопки, вторичный золотой |
| `--c-cyan` | #22B8E6 | Технологические акценты, статусы, AI |
| `--c-text` | #F3F5F8 | Основной текст |
| `--c-text-muted` | #929CAB | Вторичный текст, подписи |
| `--c-success` | #3FBF7F | Успешно, статус «выполнено» |
| `--c-warning` | #E0A64A | Предупреждения |
| `--c-danger` | #E5544B | Ошибки, удаление |

### Правила применения цвета

- На одна� страница — один акцент действия. Основной CTA всегда `--c-gold`.
- Голубой (`--c-cyan`) **никогда** не используется для основного действия — только для AI-темы, статусов и технических меток.
- Текст на золотом фоне: `--c-bg` (тёмный), не белый — белый на #E3BC7A не проходит контраст.
- Минимальный контраст: 4.5:1 для текста, 3:1 для крупного текста и иконок.

|---|---|---|
| `--font-sans` | `'Inter', system-ui, sans-serif` | Основной текст |

| Токен | Размер / line-height / трекинг | Назначение |
|---|---|---|
| `--text-hero` | clamp(2.5rem, 6vw, 4.5rem) / 1.05 / -0.02em | H1 главного экрана |
| `--text-h1` | clamp(2rem, 4vw, 3rem) / 1.1 / -0.01em | H1 внутренних страниц |
| `--text-h2` | clamp(1.5rem, 3vw, 2.25rem) / 1.15 | H2 секций |
| `--text-h3` | 1.25rem / 1.3 | H3 карточек |

Правила: не более двух уровней заголовков в одной секции; `eyebrow` — только uppercase micro с трекингом 0.08em.

## 3. Пространство и сетка

Шкала (шаг 4px): 4, 8, 12, 16, 24, 32, 48, 64, 96, 128.

| Токен | Значение |
|---|---|
| `--space-section` | clamp(64px, 10vw, 128px) — вертикальный отступ секций |
| `--container` | 1200px |
| `--container-narrow` | 760px (текстовые страницы) |
| `--gap-grid` | 24px |

Брейкпоинты: `sm 640`, `md 768`, `lg 1024`, `xl 1280`. Мобильный — база, десктоп — расширение.

## 5. Движение

| Токен | Значение |
|---|---|
| `--ease-out` | cubic-bezier(.16,1,.3,1) |
| `--dur-fast` | 150ms |
| `--dur-med` | 250ms |
| `--dur-slow` | 500ms |

Правила: анимации только на `transform` и `opacity`; никаких тяжёлых 3D-сцен; при `prefers-reduced-motion: reduce` все анимации отключаются.

## 6. Фокус и доступность

- Все интерактивные элементы: видимое `:focus-visible` — `outline: 2px solid var(--c-cyan); outline-offset: 2px`.
- Никаких невидимых фокусов и `outline: none` без замены.
- Иконки-кнопки обязаны иметь `aria-label`.
