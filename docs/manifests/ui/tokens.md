# UI-манифест: Tokens (дизайн-токены)

**Файлы:** `frontend/src/app/globals.css` (значения), `frontend/tailwind.config.ts` (классы)
**Статус:** действует с 25.11.2026 — дизайн-система **PERSONAL v2.0**. Заменяет тёмную палитру v1 полностью.

## 1. Палитра

Графит и бумажный оттенок — основа. Лайм и терракота — акценты. **Синий основным цветом больше не является.**

| Токен | Значение | Роль |
|---|---|---|
| `--c-paper` | `#EAE7DF` | Основной фон страницы (Paper) |
| `--c-paper-2` | `#F3F0E8` | Вторичная поверхность: карточки, панели |
| `--c-ink` | `#242522` | Основной текст, тёмные секции (Graphite) |
| `--c-ink-2` | `#343631` | Вторичный текст на светлом |
| `--c-muted` | `#6E6F66` | Подписи, служебный текст |
| `--c-line` | `#D3CFC4` | Обычная граница, разделитель |
| `--c-line-2` | `#B9B3A4` | Усиленная граница, рамка панели |
| `--c-lime` | `#B9E56B` | Главный акцент: основная кнопка, выделение слова, CTA (Acid lime) |
| `--c-lime-ink` | `#24310D` | Текст поверх лайма (если нужен тёмный, а не графит) |
| `--c-terracotta` | `#D97859` | Второй акцент: маркеры, ссылки-hover, шаги схемы (Terracotta) |
| `--c-terracotta-ink` | `#3B160C` | Текст поверх терракоты |
| `--c-success` | `#3F7F4E` | Успех (светлая тема) |
| `--c-warning` | `#B07A1E` | Предупреждение |
| `--c-danger` | `#B4453A` | Ошибка, необратимое действие |

### Совместимость старых имён

Разметка, написанная до редизайна, использует имена `--c-bg`, `--c-gold`, `--c-cyan` и т. п.
Они **не удалены**, а перенаправлены на новую палитру — так редизайн идёт постранично, без «всё сразу».

| Старое имя | Теперь указывает на |
|---|---|
| `--c-bg` | `--c-paper` |
| `--c-surface` | `--c-paper-2` |
| `--c-surface-2` | `#FFFFFF` |
| `--c-border` / `--c-border-strong` | `--c-line` / `--c-line-2` |
| `--c-gold` / `--c-gold-dim` | `--c-lime` / `#A5CE58` |
| `--c-cyan` | `--c-terracotta` |
| `--c-text` / `--c-text-muted` | `--c-ink` / `--c-muted` |

Новые компоненты пишут **только новые имена**. Старые доживают до конца миграции и затем удаляются.

## 2. Тёмные секции

Тёмная секция включается классом `.on-dark` (её ставит `Section surface`): внутри роли токенов переключаются,
и компонент, написанный на `--c-text` / `--c-border`, автоматически становится читаемым на графите.

```css
.on-dark { --c-bg: var(--c-ink); --c-text: var(--c-paper); --c-gold: var(--c-lime); ... }
```

Больше двух тёмных секций подряд на странице не ставить.

## 3. Типографика

| Токен | Значение |
|---|---|
| `--font-display` | `Inter, system-ui, …` — заголовки |
| `--font-sans` | `Inter, system-ui, …` — текст |
| `--font-mono` | `JetBrains Mono, ui-monospace, monospace` — номера, служебные подписи, `uppercase tracking-[0.18em]` |

Правила:

- H1 страницы: `clamp(38px, 7vw, 92px)`, `uppercase`, `leading-[0.92]`, `tracking-[-0.03em]`. Заголовок может занимать почти всю ширину.
- H2 секции: `clamp(26px, 3.6vw, 44px)`, `uppercase`.
- Подпись-надзаголовок: моно 11px, `uppercase`, `tracking-[0.22em]`, цвет `--c-terracotta`.
- Абзац-лид: 18–20px, `leading-relaxed`, `--c-ink-2`.
- Не более трёх размеров на экран.

## 4. Сетка и ритм

| Токен | Значение |
|---|---|
| `--space-section` | `clamp(64px, 9vw, 128px)` — вертикальный отступ секций |
| `--shell-max` | `1320px` — ширина контента (сменила 1200px) |
| боковые отступы | 16 / 24 / 32px (мобильный / планшет / десктоп) |
| радиусы | `0` для кнопок, карточек и панелей; `999px` только для круглых маркеров; `8px` для полей ввода |

**Асимметрия обязательна:** одинаковые карточки в ряд допустимы только для списков однотипных сущностей (каталог услуг).
Первый экран, «Обо мне», CTA — собираются из неравных колонок и крупной типографики.

## 5. breakpoints

| Точка | Что происходит |
|---|---|
| 375px | базовая колонка, крупный H1 ужимается через `clamp` |
| 640px | карточки в 2 колонки, появляется CTA в шапке |
| 768px | планшетные сетки |
| 1024px | `lg`-сетки, боковые отступы 32px |
| 1280px (`xl`) | полное меню в шапке (до этого — бургер) |

## 6. Состояния

| Состояние | Правило |
|---|---|
| `:focus-visible` | `outline: 2px solid var(--c-terracotta); outline-offset: 2px` |
| hover ссылки | `--c-terracotta` (на светлом), `--c-lime` (на графите) |
| disabled | opacity .45, `cursor: not-allowed` |

## 7. Запрещено

- Новые цвета без согласования: любой HEX в компоненте — дефект, кроме `globals.css`.
- `rgba(...)` со старыми каналами (синий/золотой) — наследие v1.
- Тёмная тема `color-scheme: dark` — отменена, сайт светлый.
- Синий и золотой как акцентные цвета.
