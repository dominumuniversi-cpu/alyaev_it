# Манифест: Header (шапка сайта)

**Файл:** `frontend/src/components/layout/Header.tsx` · **Статус:** обязателен на всех публичных страницах

## Назначение
Единая точка навигации и главный CTA. Видна на каждой странице, кроме кабинета и админки.

## Структура
| Элемент | Обязателен | Примечание |
|---|---|---|
| Логотип-текст «Дмитрий Аляев» | да | ведёт на `/`, aria-label «Дмитрий Аляев — на главную» |
| Меню: Услуги, Портфолио, Обо мне, Блог, Контакты | да | порядок фиксирован |
| Кнопка «Обсудить проект» | да | вариант Button primary, ведёт на `/contacts/#lead` |
| Кнопка мобильного меню | да | только < 1024px |
| Индикатор текущей страницы | да | aria-current="page" |

## Поведение
- Высота: 64px мобильный, 72px desktop. При прокрутке > 8px добавляет фон и нижнюю границу.
- Фиксирована сверху (position sticky), не перекрывает контент.
- Мобильное меню: полноэкранная панель, закрытие по Esc, клику вне и выбору пункта. Фокус запирается внутри панели.
- Никаких перезагрузок: навигация — обычные ссылки Next Link.

## Запрещено
- Прозрачная шапка поверх текста без подложки при прокрутке.
- Дубли пунктов меню.
- Кнопка «Войти» в основной навигации: вход клиента — из подвала на первом этапе.

## Доступность
- header и nav с aria-label «Основная навигация».
- Кнопка меню: aria-expanded, aria-controls.
- Контраст текста меню не ниже 4.5:1.
