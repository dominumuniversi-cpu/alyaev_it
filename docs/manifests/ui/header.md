# Манифест: Header (шапка сайта)

**Файл:** `frontend/src/components/layout/Header.tsx` · **Статус:** обязателен на всех публичных страницах
**Дизайн:** PERSONAL v2.0 — светлая бумага, графитовый текст, моно-подписи, лаймовая/графитовая CTA.

## Назначение
Единая точка навигации и главный CTA. Видна на каждой странице, кроме кабинета и админки.

## Структура
| Элемент | Обязателен | Примечание |
|---|---|---|
| Логотип-текст «Дмитрий Аляев» | да | `uppercase`, `tracking-[0.14em]`, фамилия — цветом `--c-terra-ink`; ведёт на `/`, aria-label «Дмитрий Аляев — на главную» |
| Меню: Услуги, Портфолио, Обо мне, Блог, Калькулятор, Разбор процесса, Контакты | да | порядок фиксирован; 13px, `uppercase`, `tracking-[0.08em]` |
| Кнопка «Обсудить проект» | да | CTA — компонент `ButtonLink` (лаймовая плашка `--c-lime`, текст `--c-lime-ink`): форма и размеры правятся в `lib/design/ui.ts`
| Кнопка мобильного меню | да | только < 1280px (`xl`) |
| Индикатор текущей страницы | да | `aria-current="page"` + подчёркивание лаймом, толщина 2px, `underline-offset-8` |

## Поведение
- Фон шапки — всегда `--c-paper` (никакой прозрачности поверх текста). При прокрутке > 8px добавляется нижняя граница `--c-line` и `backdrop-blur`.
- Высота: 64px мобильный, 76px desktop. `position: sticky; top: 0; z-50`.
- Мобильное меню: панель под шапкой, закрытие по Esc, смене маршрута и повторному клику. `aria-expanded`, `aria-controls="mobile-menu"`.
- Никаких перезагрузок: навигация — Next `Link`.

## Запрещено
- Прозрачная шапка поверх тёмного первого экрана без подложки.
- Дубли пунктов меню.
- Кнопка «Войти» в основной навигации: вход клиента — из подвала.
- Сырые HEX в разметке (было `#0A0C12`, `#EFCF98` — заменено на токены).

## Доступность
- `header` + `nav aria-label="Основная навигация"`; мобильная — `aria-label="Мобильная навигация"`.
- Контраст текста меню не ниже 4.5:1 (`--c-ink` на `--c-paper` ≈ 13:1; `--c-muted` на бумаге ≈ 5.2:1).
- Кнопка меню имеет `aria-label` «Открыть/Закрыть меню».
