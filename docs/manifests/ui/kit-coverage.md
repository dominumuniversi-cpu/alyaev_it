## Не взято — и почему

| Элемент пакета | Причина | План |
|---|---|---|
| Растровые декоративные фоны (`bg-circuit-*`, `bg-earth-network`, `bg-wave`) | Пакет требует «фон = инфраструктура, а не картинка ради картинки»; тяжёлый растр бьёт по LCP (≤2,5 с). Проверено 26.11.2026: фон восстанавливается из CSS-сетки, владелец его видит | ОТКРЫТЫЙ ВОПРОС владельцу: если хочет именно растровый фон — берём `bg-circuit` только на внутренних страницах и только затемнённым до 6–8% прозрачности. Ждёт ответа |
| `visual-assets-board.webp` | Служебная доска дизайнера, не элемент сайта | не берём |
| Иконочные листы как картинки | На страницу не грузятся как растры: те же иконки в SVG-компоненте `Icon` — они и есть содержимое листов | Работает как у пакета: источник один, вывод — SVG |
| `visual-assets-board.webp` → раздел «Сцены» | Доска разобрана по срезам; сцены (`HeroArt`, `PortfolioVisual`, строки услуг) написаны по ней в SVG | взято композиционно |
| `USAGE.example.tsx` / `PersonalHome.tsx` | Это демонстрация композиции под Next-страницу пакета, а не готовые компоненты сайта. **Композиция взята**: строки услуг (`ServiceRow`), процесс в 5 шагов, CTA-плашка лаймом. Сам код не копируется — на сайте свои компоненты и данные из БД | эталон, а не зависимость |

## Как пользоваться

1. Взял новый элемент пакета — перенеси строку из «Не взято» в «Взято» с указанием места и проверки.
2. Отказ от элемента — пиши причину здесь, а не держи в голове.
3. Ссылки на конкретные файлы пакета давай относительными путями от `docs/personal-theme-v2-starter`.
