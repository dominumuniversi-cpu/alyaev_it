# Манифест: Footer (подвал)

**Файл:** `frontend/src/components/layout/Footer.tsx` · **Дизайн:** PERSONAL v2.0 — графитовая полоса `--c-ink`, текст `--c-paper`.

## Структура
| Колонка | Содержимое |
|---|---|
| Бренд | «Дмитрий Аляев» крупно (`clamp(28px,4vw,44px)`, uppercase), фамилия — лаймом; ниже моно-подпись «AI · Автоматизация · Интеграции» и одно предложение позиционирования |
| Разделы | Услуги, Портфолио, Обо мне, Блог, Калькулятор, Разбор процесса, Контакты |
| Услуги | 6 ссылок на страницы услуг из БД |
| Документы | Политика конфиденциальности, Согласие на обработку ПД + контакты |

Нижняя строка: © {год} Дмитрий Аляев + ссылка «Вход для клиентов» на `/login/` — моно 11px, `uppercase`, `tracking-[0.16em]`.

## Визуальные правила
- Фон — `--c-ink`, разделители — `--c-border-strong` (внутри тёмной палитры).
- Заголовки колонок: `--font-mono`, 11px, `uppercase`, `tracking-[0.18em]`, цвет `--c-text-muted`.
- Hover ссылок — `--c-lime`. Ссылки не подчёркнуты в покое.
- Бренд-блок занимает колонку `1.2fr` в сетке `lg:grid-cols-[1.2fr_1fr_1fr_1fr]`.

## Правила
- Контакты берутся из `site_settings.contacts`: пустые значения не выводятся, а не показываются заглушками.
- Год вычисляется на сервере.
- Внутренние ссылки — Next `Link`.
- Подвал — тёмная секция страницы; второй тёмной секции подряд быть не должно.
