# Манифест: Footer (подвал)

**Файл:** `frontend/src/components/layout/Footer.tsx` · **Сверено с кодом 26.11.2026**

## Вид

| Свойство | Значение |
|---|---|
| Фон | `--c-paper-2` поверх `--c-paper` страницы; рамка сверху — `--c-line` |
| Текст | роли темы: `--c-ink`, `--c-muted`, ссылки — `--c-terra-ink` при наведении |
| Сетка | `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`, зазор `gap-10` |
| Бренд | `text-lg` (18px), `--font-display`, uppercase, `tracking` |
| Год | вычисляется от текущей даты, не хардкодится |

## Правила

1. Подвал **не** тёмный: в новой теме он светлый, чтобы не было «тяжёлого низа». В тёмной теме он автоматически
   берёт тёмные роли — отдельная логика не нужна.
2. Ссылки на услуги подтягиваются из БД (`fetchServices`), навигация совпадает с шапкой.
3. Контакты берутся из настроек, а не из текста разметки.
4. Внешние ссылки — `target="_blank" rel="noopener noreferrer"`.
