# Манифест: Правовые страницы (`/privacy/`, `/personal-data-consent/`, `/reviews/`)

**Файлы:** `frontend/src/app/privacy/page.tsx`, `personal-data-consent/page.tsx`, `reviews/page.tsx`

| Страница | Правило |
|---|---|
| `/privacy/` | одна колонка, `max-w-[min(100%,74ch)]`, кегль тела 16px, подзаголовки H2 20–26px; никаких карточек |
| `/personal-data-consent/` | та же типографика; текст согласия без сокращений, дата редакции моно-кеглем |
| `/reviews/` | при отсутствии отзывов — честная пустая страница с объяснением, а не демонстрационные отзывы |
| Общее | крошки, один H1, `Section`, роли темы; ссылки на контакты — `ButtonLink` |

**Почему манифест общий:** три страницы делят одну типографику и не имеют собственных компонентов —
отдельные файлы разошлись бы при первой же правке.
