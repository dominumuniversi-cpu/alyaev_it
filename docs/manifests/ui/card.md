## Card — базовая карточка

Фон `--c-surface`, граница 1px `--c-border`, радиус `--radius-lg`, padding 24px, тень `--shadow-card`.

| Состояние | Вид |
|---|---|
| default | граница `--c-border` |
| hover (если кликабельна) | граница `--c-border-strong`, `transform: translateY(-2px)` |
| focus-within | outline 2px `--c-cyan` |

Кликабельная карточка — это `<a>` вокруг всей карточки; вложенные ссылки запрещены (только одна зона клика + отдельная ссылка-кнопка вне ссылки).

## ServiceCard — карточка услуги (ТЗ, блок 4)

```
┌──────────────────────────────┐
│ [иконка]         [тип: gold] │
│ Название услуги              │
│ Короткое описание (1–2 стр.) │
│ • пример задачи 1            │
│ • пример задачи 2            │
│ • пример задачи 3            │
│ ──────────────────────────── │
│ от 6 000 ₽       3–5 дней    │
│ [Подробнее →]                │
└──────────────────────────────┘
```

Обязательные поля (из БД `services`): `title`, `short_description`, `price_from`, `price_currency`, `duration_text`, `examples[]`, `slug`.

Правила:
- Цена — «от N ₽» (если `price_from` задан), никогда вымышленная.
- Если цена по запросу: «по оценке» и кнопка того же вида.
- Срок — из БД (`duration_text`), например «3–5 дней» или «по ТЗ».
- Метка категории — `tech`-стиль с `--c-cyan`.

## Антипаттерны

- Карточка без цены или срока на странице услуг.
- Более 3 строк описания в карточке.
- Кнопка внутри карточки, которая не ведёт на страницу услуги.
