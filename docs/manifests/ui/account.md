# Манифест: Личный кабинет клиента (AccountShell)

**ТЗ 9.1, 9.3, 11.5.** Компонент: `src/components/account/AccountShell.tsx`.
Страницы: `/account` (список), `/account/projects/[id]` (карточка).

## Ключевое правило

Данные приходят **только по cookie сессии**, поэтому кабинет рендерится на клиенте.
Серверный рендер увидел бы пустой кабинет и показал бы «проектов нет» даже тем, у кого они есть.

Изоляция проектов при этом **на сервере** (`app/api/account.py`), компонент только отображает.
Скрытие элементов здесь ничего не защищает и защитой не считается (ТЗ 9.3).

## Состояния

| Состояние | Когда | Что видит клиент |
|---|---|---|
| `loading` | запрос в пути | «Загружаем…» |
| `unauth` | 401, или 404 с чужим/несуществующим проектом | «Нужен вход» + кнопка «Войти» |
| `nocabinet` | 404 с текстом «не заведён» | «Кабинет ещё не заведён» + просьба написать исполнителю |
| `ok` | данные получены | список проектов или карточка |

**Почему 404 делятся на два вида.** Сервер отвечает 404 и когда нет карточки клиента,
и когда проект чужой. Разворачиваем только первый случай — по тексту ответа.
Второй намеренно неотличим от «не существует»: иначе перебором можно узнать, что проект есть.

## Список проектов

| Элемент | Правила |
|---|---|
| Карточка проекта | вся кликабельна, ведёт на `/account/projects/<id>` |
| Название | как в базе, не обрезается |
| Статус | плашка: голубая `new`, золотая `analysis/dev/testing`, серая `done` |
| Стоимость | `12 000 ₽`; при `NULL` — **«по договорённости»**, не «0 ₽» |
| Срок | `24.11.2026`; при `NULL` — прочерк |

Пустой список — честная строка «Проектов пока нет», а не заглушка и не пустая сетка.

## Карточка проекта

Три блока по порядку: **описание и цифры → задачи → история**.

- Задачи: невыполненные выше выполненных, выполненные помечены `✓`.
- История: дата + статус + комментарий, в хронологическом порядке.
- Пустые блоки пишут «Задач пока нет» / «Изменений пока не было», а не исчезают.

## Обязательные правила

- `robots: { index: false, follow: false }` на всех страницах кабинета (ТЗ 11.5).
- Кнопка «Выйти» есть на обеих страницах: из карточки не должно быть ловушки.
- При сбое сети при выходе всё равно уводим на вход: показать кабинет после «выхода» хуже.
- Цена `NULL` ≠ ноль. «По договорённости» и «бесплатно» — разные вещи.
