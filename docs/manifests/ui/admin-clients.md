# Манифест: страница админки «Клиенты» (`/admin/clients/`)

> Источник требований: ТЗ §9.2 (кабинет администратора), §9.4 (создание учётной записи админом).
> Смежные манифесты: `ui/admin-layout.md`, `ui/field.md`, `ui/button.md`, `ui/badge.md`, `db/schema.md`.

## Назначение

Даёт администратору завести клиента и выдать ему вход в кабинет. Без этой страницы кабинет
клиента работает, но попасть в него невозможно — учётные записи некому создавать.

**Клиент не регистрируется сам** (ТЗ §9.4). Открытой регистрации на сайте нет.

## Компоновка

| Порядок | Блок | Обязательность |
| --- | --- | --- |
| 1 | `AdminNav` с `current="/admin/clients/"` | всегда |
| 2 | `h1` «Клиенты и доступ» | всегда |
| 3 | Пояснение под `h1` | всегда |
| 4 | Карточка «Данные для входа» | только после выдачи или перевыпуска |
| 5 | Строка уведомления (`role="status"`) | только после действия |
| 6 | Форма «Новый клиент» | всегда |
| 7 | Таблица клиентов | при наличии клиентов |
| 8 | Пустое состояние | при нуле клиентов |

`max-w-[1200px]` — как у всех админских страниц.

Индексация закрыта: `robots: { index: false, follow: false }`.

## Элементы

### Форма «Новый клиент»

| Элемент | Тип | Имя поля | Обязательность | Правило |
| --- | --- | --- | --- | --- |
| Имя или название | `TextField` | `display_name` | да | максимум 200 символов |
| Компания | `TextField` | `company` | нет | максимум 200 символов |
| Создать клиента | `Button type="submit"` | — | — | отправка через `fetch`, без перезагрузки |

После успешного создания форма очищается, список обновляется точечно. Страница не перезагружается.

### Таблица клиентов

| Колонка | Содержимое |
| --- | --- |
| Клиент | имя; второй строкой компания, если есть |
| Проекты | число проектов |
| Доступ | `Badge` «выдан» (`tech`) или «нет входа» (`muted`) |
| Создан | дата в формате `ДД.ММ.ГГГГ`; пустое → `—` |
| Действия | одна кнопка по состоянию доступа |

### Кнопки действий

| Условие | Кнопка | Что делает |
| --- | --- | --- |
| `has_login = false` | «Выдать доступ» | спрашивает почту, создаёт учётную запись с ролью `client` |
| `has_login = true` | «Перевыпустить пароль» | новый пароль, **все сессии клиента завершаются** |

Пока запрос идёт, кнопка показывает `…` и заблокирована — защита от двойного нажатия.

### Карточка «Данные для входа»

Появляется после выдачи или перевыпуска.

- Почта и пароль моноширинным шрифтом; пароль выделяется одним движением (`select-all`).
- Текст предупреждения берётся **с сервера** (`warning`), а не пишется в интерфейсе:
  правило должно жить в одном месте.
- Кнопка «Я сохранил пароль» убирает карточку.

**Пароль показывается один раз.** В базе хранится только хеш — восстановить его нельзя,
только перевыпустить. Это сознательное ограничение, а не недоработка.

## Состояния экрана

| Состояние | Что видно |
| --- | --- |
| `loading` | «Загружаем…» |
| `error` | «Не удалось загрузить клиентов» (`role="alert"`) |
| 401 / 403 | переход на `/login/` |
| пусто | «Клиентов пока нет. Создайте первого — затем выдайте ему доступ.» |
| готово | таблица |

## Ошибки сервера на экране

Текст берётся из `detail` ответа — сервер уже пишет по-русски и по делу.

| Код | Что покажется |
| --- | --- |
| 409 (выдача) | «Доступ уже выдан. Чтобы сменить пароль, перевыпустите его.» |
| 409 (почта) | «Пользователь с такой почтой уже существует» |
| 404 | «Клиент не найден» |

Если `detail` нет — общий текст, а не пустая строка и не код ошибки.

## Доступ

| Действие | Требуемое право |
| --- | --- |
| список, создание клиента | `projects:all` |
| выдача доступа, перевыпуск пароля | `users:manage` |

Права проверяются на сервере. Скрытие кнопки в интерфейсе защитой не считается (ТЗ §9.3).

## Журнал действий

| Действие | Запись |
| --- | --- |
| создание клиента | `client.create` |
| выдача доступа | `client.access_granted` |
| перевыпуск пароля | `client.password_reset` |

**Пароль в журнал не попадает никогда.**

## Связанные API

- `GET /api/v1/admin/clients`
- `POST /api/v1/admin/clients`
- `POST /api/v1/admin/clients/{id}/access?email=...`
- `POST /api/v1/admin/clients/{id}/reset-password`

## Что осталось

- Проекты и задачи ведутся через API; экрана пока нет.
- Восстановление пароля по почте не реализовано (нужен почтовый провайдер).
