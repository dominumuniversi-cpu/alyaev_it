# Манифест: Загрузка файлов

**ТЗ 12.5:** «проверка загружаемых файлов» — обязательное требование безопасности.
Загрузка нужна портфолио (картинки кейсов) и кабинету (документы по проектам).

## Где хранятся файлы

Файлы лежат на диске **вне образа**, иначе исчезнут при пересборке:

| Среда | Путь |
|---|---|
| В контейнере | `/app/media` |
| На хосте | `E:\DockerData\alyaev-it\media` |

В базе хранится только **метаданные** и относительный путь.
Раздел `media` включается в резервное копирование, но отдельно от дампа базы.

### Правило: имя файла от нас, а не от пользователя

Имя из запроса **никогда не используется как путь**. Генерируем своё:
`<uuid>.<расширение>`, где расширение берётся из **проверенного** типа.
Причина: имя вида `../../nginx.conf` или `a;rm -rf /` — это path traversal и инъекция.

## Что разрешено

| Тип | Расширения | Максимум |
|---|---|---|
| Изображения | `.png`, `.jpg`, `.jpeg`, `.webp` | 5 МБ |
| Документы | `.pdf`, `.docx`, `.xlsx`, `.zip` | 20 МБ |

**Проверка по содержимому, а не по имени.** Расширение пишет пользователь,
а первые байты файла подделать сложнее. Проверяем магические байты:
PNG `89 50 4E 47`, JPEG `FF D8 FF`, WebP `RIFF....WEBP`, PDF `%PDF`.

**Запрещено всегда:** `.exe`, `.bat`, `.cmd`, `.ps1`, `.js`, `.html`, `.svg`, `.php`.

`svg` и `html` — не картинки и не документы, а исполняемые в браузере файлы.
SVG умеет содержать скрипт, HTML — тем более. Их загрузка открыла бы XSS
для всех посетителей сайта.

## Правила

1. Лимит размера проверяется **до** чтения в память, а не после.
2. Тип определяется по содержимому; не совпало с разрешённым — 422.
3. Имя генерируем сами; исходное имя сохраняем в базе только для показа.
4. Загружать может только пользователь с правом `content:write`.
5. Удаление — soft-delete: файл остаётся на диске, пока не почистим вручную.

## Чего НЕ делаем

- Не отдаём файлы прямым путём через nginx: только через API, чтобы проверять права.
- Не исполняем ничего из загруженного.
- Не храним файлы в базе (`bytea`) — база не для этого, а дамп вырастет.
